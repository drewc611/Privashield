# PrivaShield

Local-first privacy and threat detection platform. FastAPI control plane, two
Python sensor services, a dependency-free static dashboard.

## Commands

```sh
make install        # create .venv on Python 3.12 and install with dev tooling
make verify         # every gate CI runs; if this passes, CI passes
make format         # apply formatting and safe lint fixes
make lock           # regenerate lockfiles after changing pyproject.toml deps
make help           # all targets
```

Always use `make verify` before pushing rather than running tools ad hoc. It is
the same gate set CI runs, in the same order.

The project requires Python 3.12. Do not use the ambient interpreter; `make`
targets run out of `.venv/`.

## Layout

- `apps/api/privashield_api/` - FastAPI control plane; routes in `routes/`
- `apps/dashboard/` - static HTML/CSS/JS served by nginx, no build step
- `services/collector/` - Suricata and Zeek log collector
- `services/file-monitor/` - host filesystem monitor
- `evaluation/` - detection corpus and regression thresholds
- `requirements/` - hash-pinned lockfiles, generated only by `make lock`
- `.github/agents/`, `.github/agent-policy.json` - agent governance, validated in CI

## Invariants

Dependencies are declared as ranges in `pyproject.toml` and resolved into
hash-pinned lockfiles. CI installs with `--require-hashes` and runs `pip check`,
which fails if `pyproject.toml` declares something the lockfile lacks. Change a
dependency, then run `make lock` in the same commit.

GitHub Actions are pinned to commit SHAs with the version in a trailing comment.
Never reintroduce a mutable tag. `daily-autonomous-maintainer.lock.yml` is
generated by gh-aw; do not hand-edit it.

Coverage is a floor that may not drop. It is enforced at two decimals, because
at precision 0 a percentage rounds up past its own threshold. Raising coverage
means raising `COVERAGE_MIN` in the `Makefile` to match.

Type checking covers the whole tree. `privashield_api.database` carries one
documented mypy override for its ORM-to-Pydantic conversions. Narrow it as those
conversions are made explicit; do not add new exclusions to work around an error.

The detection benchmark runs against committed thresholds in
`evaluation/thresholds.json`. Do not lower a threshold to make a change pass.

Agent governance (`.github/scripts/validate_agent_governance.py`) asserts the
autonomous maintainer cannot merge, release, deploy, or modify secrets. Treat
those bounds as fixed.

## Conventions

Conventional-style commit subjects (`feat:`, `fix:`, `ci:`, `docs:`, `test:`,
`build:`, `chore:`). Small, focused changes. Tests with every behavior change.
Update docs in the same PR when behavior changes, and do not document components
that do not exist yet.

The dashboard is intentionally dependency-free. Adding a build step or package
manager needs an ADR under `docs/adr/`.

There is no migration tooling yet; the API creates its schema at startup from
SQLAlchemy metadata as a Phase 1 bootstrap. Do not describe it as a safe upgrade
path.
