# Code of Conduct

PrivaShield contributors are expected to keep technical discussion professional, evidence-based, and focused on improving the project.

## Expected behavior

- Treat contributors and users with respect.
- Critique code, architecture, tests, and claims rather than people.
- Provide reproducible evidence for security or performance assertions where practical.
- Respect privacy and do not publish another person’s private information.
- Follow responsible-disclosure procedures for vulnerabilities.
- Accept that security-sensitive changes may require additional review and testing.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, targeted abuse, doxxing, deliberate disruption, knowingly misleading security claims, or publishing sensitive exploit details contrary to `SECURITY.md` are not acceptable.

## Enforcement

Maintainers may edit or remove content, close discussions, reject contributions, restrict participation, or ban contributors when behavior materially harms the project or its community. Security emergencies may require immediate action before a broader review.

Questions about conduct should be directed privately to the repository maintainers.
