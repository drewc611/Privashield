# Support

PrivaShield is currently pre-alpha and does not yet provide production support guarantees.

## Where to ask

Use GitHub issues for reproducible bugs, feature requests, documentation problems, and installation problems that do not contain sensitive information.

Do not use public issues for vulnerabilities, exploit chains, credentials, private packet captures, customer telemetry, or personal data. Follow `SECURITY.md` for those cases.

## Include with support requests

- operating system and architecture
- PrivaShield version or commit SHA
- deployment method
- relevant configuration with secrets removed
- expected behavior
- observed behavior
- minimal reproduction steps
- relevant logs after redaction

## Project status

Until a supported release channel is announced, interfaces, schemas, configuration, and packaging may change between commits. Pin a specific release or commit when evaluating the project.
